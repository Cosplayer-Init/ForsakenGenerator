I Decided to Create a Generator Macro for forsaken, that automatically does the generator puzzle for you. You can make it slow or really fast by using the presets, or custom, Lightning Fast bypasses the max and minimum values for the speed recovery settings. * NOTE * WHEN YOU JOIN A FORSAKEN GAME, YOU MUST COMPLETE ONE GENERATOR BEFORE DOING THE MACRO BECAUSE IT OFFSETS THE PUZZLE FOR THE FIRST TIME!!!

Press F3 to start the macro, F4 to scan the macro and show it on the Scan Graph, Press F5 to stop the macro while its in action.
